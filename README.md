# СФиИР

СФиИР (Системы Формирования и Исполнения Решений)

Настольное приложение для моделирования автоматизированной системы управления вычислительными процессами (АСУ). Проект позволяет исследовать, как параметры входящего потока, доступная память и квант процессорного времени влияют на обработку заявок.

## Как работает симуляция

Заявки поступают в систему в случайные моменты времени и содержат требования к памяти и процессорному времени. Система обрабатывает их с учётом заданного объёма памяти: если заявке не хватает памяти, она ожидает освобождения ресурсов, а заявка, требующая больше памяти, чем есть во всей системе, отклоняется. Для принятых заявок создаются процессы, которые выполняются по алгоритму кругового планирования Round Robin: каждому процессу выделяется заданный квант CPU, после чего незавершённый процесс возвращается в очередь.

Поток заявок моделируется экспоненциальным распределением, требования к памяти — экспоненциальным распределением, а длительность выполнения — распределением Пуассона. Начальное значение генератора псевдослучайных чисел (seed) позволяет повторить прогон с теми же входными данными.

## Возможности приложения

- Настройка интенсивности поступления заявок, распределения объёма памяти и процессорного времени, времени моделирования, лимита поступления заявок, объёма памяти системы, кванта CPU и seed.
- Просмотр интервалов выполнения процессов и результатов моделирования: числа и доли выполненных заявок, загрузки системы, использования памяти, времени ожидания и выполнения.
- Изучение графиков используемых распределений.
- Сравнение результатов при изменении выбранных параметров, а также просмотр OLAP-результатов для пакетных прогонов.

## Состав решения

- **SFiIR.App** — настольный интерфейс на Avalonia: настройки симуляции, визуализация процессов, статистика, распределения и сравнение параметров.
- **SFIiR.Modeling** — модель заявок и процессов, алгоритм симуляции и сбор статистики.
- **SFIiR.Random** — генератор псевдослучайных чисел и генерация величин с экспоненциальным распределением и распределением Пуассона.
- **SFiIR.DbFill** — утилита пакетного запуска симуляций и сохранения агрегированных результатов в PostgreSQL для OLAP-анализа.

## Требования и запуск

Для сборки и запуска требуется .NET 10 SDK. Из корня репозитория запустите графическое приложение:

```bash
dotnet run --project SFiIR.App
```

Чтобы собрать всё решение, выполните:

```bash
dotnet build SFiIR.slnx
```

Для заполнения OLAP-данных и просмотра OLAP-результатов также требуется настроенная база PostgreSQL.
